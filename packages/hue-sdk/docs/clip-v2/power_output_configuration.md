# /resource/power_output_configuration

API to manage power output configuration services. These are offered by devices with configurable power output modes.

## /resource/power_output_configuration

### GET /resource/power_output_configuration

List all resources of this type

> Secured by hue-application-key API authorization using a hue-application-key header

#### Response

##### HTTP status code 200

Request was on resource path was successful. Result of request is in data.

###### Body

**Media type**: application/json

**Type**: object

**Properties**

- **errors**: *(required, array of [APIError](./common.md#apierror))*
- **data**: *(required, array of PowerOutputConfigurationGet)*
  **Items**: PowerOutputConfigurationGet
  - **id**: *(required, string – pattern: ^[0-9a-f]{8}-([0-9a-f]{4}-){3}[0-9a-f]{12}$)*
    Unique identifier representing a specific resource instance
  - **id_v1**: *(string – pattern: ^(\/[a-z]{4,32}\/[0-9a-zA-Z-]{1,32})?$)*
    Clip v1 resource identifier
  - **owner**: *(required, [ResourceIdentifier](./common.md#resourceidentifier))*
    Owner of the service, in case the owner service is deleted, the service also gets deleted
  - **type**: *(required, power_output_configuration)*
    Type of the supported resources
  - **linked_services**: *(required, array of [ResourceIdentifier](./common.md#resourceidentifier))*
    List of associated services
  - **output_mode**: *(required, object)*
    - **status**: *(required, one of set, changing)*
    - **mode**: *(required, one of controllable, always_on)*
      Current mode (on read) or requested mode (on write) of the (linked) light service
    - **mode_values**: *(required, array of PowerOutputModeType)*
      The modes that the device supports
